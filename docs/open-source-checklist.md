# Open Source Checklist

发布前逐项检查：

- [ ] 没有个人笔记、日报、项目经历。
- [ ] 没有课程原文、教材 PDF、截图或版权材料。
- [ ] 没有 API key、token、cookie、账号信息。
- [ ] 没有本地绝对路径、设备信息或用户目录名。
- [ ] 没有 `.obsidian/plugins/` 插件源码。
- [ ] 没有 `.obsidian/workspace.json` 本地布局。
- [ ] 没有 `.claudian/sessions/` 或其他 AI 会话记录。
- [ ] README 说明了安装方式、插件依赖和使用方法。
- [ ] `!_home.md` 能作为 vault 的方法入口。
