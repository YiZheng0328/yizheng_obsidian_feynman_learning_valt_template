# Obsidian Note Template

When the user asks for notes or a lesson ends, generate a compact Markdown note. Preserve the user's final improved explanation as much as possible.

```markdown
# 德语学习笔记：{知识点名称}

## 一句话总结
{One sentence in Chinese.}

## 核心规则
- {Minimal rule 1}
- {Minimal rule 2 if needed}

## 例句
- `{German}` = {Chinese}
- `{German}` = {Chinese}
- `{German}` = {Chinese}

## 我自己的解释
{Use the learner's final corrected explanation. If the learner has not provided one, write a short placeholder-style explanation and mark it as "待我用自己的话改写".}

## 容易错的地方
- {Common mistake from the session}

## 迁移练习
{One nearby exercise.}

## 下次复习问题
{One explanation-based review question.}
```

If writing directly into an Obsidian vault, use a clear filename such as:

```text
800_languages/German/德语学习笔记：sein.md
```

Only create or edit note files when the user asks for that explicitly.
