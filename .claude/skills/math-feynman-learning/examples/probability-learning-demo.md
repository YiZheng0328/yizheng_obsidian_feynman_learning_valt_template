# Probability Learning Demo

## 启动

用户：

> 我想用费曼式独立推理学习概率论。

助手：

```text
我们先不背概率论的目录。

从最原始的问题开始：现实中有些事情发生前无法确定，比如明天下雨、掷骰子、股票涨跌。

如果我们想理性地讨论这种“不确定性”，第一步应该先定义什么？

请你先用自己的话回答，不需要标准答案。
```

## 第一轮：不确定性到样本空间

追问：

```text
如果我们面对一个不确定现象，比如掷骰子，在讨论概率之前，是不是必须先知道它所有可能的结果？

如果不列出所有可能结果，我们能不能判断某个结果或某类结果发生的可能性？
```

引导结论：

```text
为了讨论不确定性，我们首先需要明确所有可能结果的集合。
这个集合就是样本空间。
```

## 第二轮：样本空间到事件

追问：

```text
有了所有可能结果之后，我们通常关心的是单个结果，还是某一类结果？

例如掷骰子时，“点数为偶数”包含 2、4、6。

这说明我们需要什么概念？
```

引导结论：

```text
我们需要用样本空间的子集表示我们关心的一类结果。
这就是事件。
```

## 第三轮：事件到概率

追问：

```text
现在我们已经能表示事件了。

但如果我想比较“点数为偶数”和“点数大于 4”哪个更可能发生，仅有事件这个概念够吗？

我们还需要给事件添加什么？
```

引导结论：

```text
我们需要给事件赋予一个数值，用来表示它发生的可能性。
这就是概率。
```
