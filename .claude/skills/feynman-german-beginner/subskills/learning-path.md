# Beginner German Learning Path

Use this path as a default order. Do not force it if the user asks for a specific topic.

## Stage 1: Minimal Self-Introduction

Goal: the user can produce a basic self-introduction.

Topics:

1. German alphabet and pronunciation basics
2. Pronouns: `ich`, `du`, `er`, `sie`, `es`, `wir`, `ihr`, `sie/Sie`
3. `sein` basics
4. `haben` basics
5. identity sentences
6. state sentences
7. origin sentences

Example sentences:

```text
Ich bin ...
Ich bin Student.
Ich komme aus China.
Ich habe ein Buch.
Ich lerne Deutsch.
```

Feynman prompt:

```text
请你解释一下：为什么 "Ich bin Student" 里的 bin 会随着 ich 出现？
```

## Stage 2: Sentence Skeleton

Goal: the user understands the basic shape of German statements and yes/no questions.

Topics:

1. subject
2. verb-second principle
3. object
4. adjective as state description
5. simple `nicht`
6. yes/no question order

Examples:

```text
Ich lerne Deutsch.
Du trinkst Kaffee.
Er spielt Fußball.
Ich bin nicht müde.
Lernst du Deutsch?
```

Core idea:

```text
德语陈述句中，变位动词通常放在第二位。
```

Feynman prompt:

```text
请你用自己的话解释一下：为什么德语里动词的位置特别重要？
```

## Stage 3: Nouns, Gender, Articles

Goal: the user understands that gender and article are part of learning a German noun.

Topics:

1. nouns are capitalized
2. masculine `der`
3. feminine `die`
4. neuter `das`
5. indefinite articles `ein/eine`
6. gender cannot always be guessed from meaning
7. article as part of noun information

Examples:

```text
der Tisch
die Lampe
das Buch
Das ist ein Tisch.
Das ist eine Lampe.
Das ist ein Buch.
```

Feynman prompt:

```text
请你解释一下：为什么学德语名词时，不能只背 Buch，而应该背 das Buch？
```

## Stage 4: Verb Conjugation Basics

Goal: the user understands that verb forms change with the subject.

Topics:

1. infinitive
2. stem
3. common present-tense endings
4. `lernen`
5. `kommen`
6. `heißen`
7. a few irregular verbs without deep exception tables

Examples:

```text
ich lerne
du lernst
er lernt
wir lernen
ihr lernt
sie lernen
```

Feynman prompt:

```text
请你假装教别人，解释一下 lernen 为什么在 ich 后面是 lerne，在 du 后面是 lernst。
```

## Stage 5: Case Basics

Goal: give only the first useful idea of case, especially masculine accusative.

Topics:

1. nominative: who does or is something
2. accusative: the object affected by an action
3. first article changes
4. masculine accusative: `der -> den`, `ein -> einen`

Examples:

```text
Der Mann sieht den Hund.
Ich habe einen Kaffee.
Ich kaufe ein Buch.
Ich sehe eine Frau.
```

Feynman prompt:

```text
请你解释一下：为什么 "Ich habe einen Kaffee" 里不是 ein Kaffee？
```

## Stage 6: Usable Expressions

Goal: build practical beginner expression around everyday scenarios.

Topics:

1. self-introduction
2. ordering food or drinks
3. asking directions
4. time
5. numbers
6. family
7. study
8. daily activities

For each scenario, include:

- 5-10 core words
- 3-5 core sentence patterns
- 1 mini dialogue
- 1 Feynman explanation
- 1 transfer exercise
